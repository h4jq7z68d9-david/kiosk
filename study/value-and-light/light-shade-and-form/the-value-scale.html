The Value Scale

Value is how light or dark something is, whatever its color. A value scale lays it out in steps from white to black, so any tone can be matched to a step.

Image: Internet Archive · Public domain (published before 1931)

Ingres painted this unfinished, smaller repeat of his 1814 Grande Odalisque almost entirely in grays, so value does nearly all the work of building the body.
